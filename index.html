FAQ

Do I need to know HTML or CSS?

No — everything is point-and-click. If you do know HTML, you'll appreciate that the exported file stays clean and semantic.

Is it really free? Any sign-up?

Yes and no — no accounts, no trials, no paywalls. It's a plain HTML/JS app you can even run from a local file.

Where does my content go?

Nowhere. All editing happens in this browser tab; nothing is uploaded. Save As writes a clean HTML file to your computer.

Can I edit existing pages?

Yes — click Open (or Ctrl+O), pick any local .html file, and edit it visually.

Does it work offline?

After the page loads, you can go offline and keep editing. (Only one-click PDF export needs the network for its rendering libraries — printing works offline.)
